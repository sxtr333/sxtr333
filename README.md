В программе:  
`Python` · `NumPy` · `Matplotlib` · `Keras` · `TensorFlow` · `PyTorch` · `Computer Vision` · `NLP` · `LLM` · `LangChain` · `FastAPI` · `Docker` · `SQL` · `Spark` · `MLflow` · `MLOps` · `Kafka` · `CI/CD` · `Kubernetes`

- Python: базовые типы, циклы, структуры данных, функции, модули, ООП и анализ данных
- Нейронные сети: Keras, TensorFlow и PyTorch
- Computer Vision: детекция объектов, сегментация, OCR и OpenCV
- NLP: BERT, T5, NER, трансформеры, NLTK, RNN и LSTM
- LLM: ChatGPT, prompt engineering, embeddings, LangChain и базы знаний
- Machine Learning: классические модели, кластеризация и рекомендательные системы
- Backend & DevOps: Linux, Bash, FastAPI, Docker, SQL/PostgreSQL, CI/CD и Kubernetes
- Data Engineering & MLOps: Spark, Hadoop, PySpark, Hive, ClickHouse, Airflow и MLflow
